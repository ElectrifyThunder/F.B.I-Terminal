HOW TO USE THE PROGRAM:

At the login screen, the default account name is: Username: Default Password: Default
Or in order to make your own account, click on the “New Account”  button, and click Login when you’re done making
the new account.  and uncheck the “New Account” box when it's successfully created. Account usernames are saved in a text file located in the folder. To successfully login into the main program, press on the Button called “Login”, make sure the “New Account” creation is showing “X New Account” if you’re not making a new account. If an error appears it most likely presents if the account is already made, or if something is missing in the folder.

At the main screen, you are greeted by a screen of 4 cameras with unique prisoner names, and the main camera in the middle is the 
 main camera in the middle is the one you are looking at right now. Along with your main Agent account username, camera number, and prisoner name in one column. Cycle through the cameras from the bottom frame row. If you want to change a prisoner's name, change the name in the Entry Box below the dedicated camera frame of the text placeholder called “New Prisoner Name”. Press “Enter” on your keyboard once you are done to save your new prisoner name, it will not be saved upon close of the program. Once you are done with the program, on the upper left there’ll be a “X” button to exit. Click that and you’re out of the program.
